# Diabetes-Risk-Analysis-and-Patient-Insights
Project Overview
This project analyzes a diabetes dataset containing patient health information such as glucose levels, BMI, blood pressure, insulin levels, age, and pregnancy history. The analysis was performed using MySQL to explore patterns and identify factors associated with diabetes diagnoses. Using MySQL for data storage, querying, and analysis, and Microsoft Excel for visualization and dashboard development, the project provides meaningful insights into patient health trends and diabetic relations.

Project Objectives

The primary goals of this project were to:

Import and manage healthcare data within a relational database environment.
Perform exploratory data analysis (EDA) using SQL queries.
Identify patterns and trends associated with diabetes diagnoses.
Compare health indicators between diabetic and non-diabetic patients.
Develop interactive visualizations and dashboards to communicate findings effectively.
Demonstrate practical data analytics skills applicable to healthcare and business intelligence domains.
Dataset Description

The dataset consists of 768 patient records and includes the following attributes:

Variable	Description
Number of pregnancies
Glucose	Plasma glucose concentration
BloodPressure	Blood pressure measurement
SkinThickness	Skin fold thickness
Insulin	Insulin level
BMI	Body Mass Index
DiabetesPedigreeFunction	Genetic predisposition indicator
Age	Patient age
Outcome	Diabetes diagnosis (0 = No Diabetes, 1 = Diabetes)
Methodology
Data Preparation

The dataset was imported into MySQL using CSV import techniques and organized into a structured database table. Data validation was conducted to ensure appropriate data types and consistent formatting.

SQL Analysis Techniques

Several SQL concepts were applied throughout the analysis process, including:

Data aggregation using COUNT(), SUM(), and AVG()
Data filtering using WHERE
Grouping data using GROUP BY
Conditional categorization using CASE
Common Table Expressions (CTEs)
Ranking and segmentation with Window Functions
Sorting and summarization techniques

Examples of analyses performed include:

Total number of patients
Diabetes prevalence rate
Average glucose levels by diagnosis status
BMI comparisons between diabetic and non-diabetic patients
Age distribution analysis
Identification of high-risk patient groups
Ranking patients based on glucose measurements
Dashboard Development

An Excel dashboard was created to provide a visual representation of the findings. The dashboard includes:

Total patient count
Diabetes prevalence percentage
Diabetes vs. non-diabetes distribution chart
Average glucose comparison chart
Average BMI comparison chart
Age group distribution visualization
Scatter plot illustrating the relationship between BMI and glucose levels
Key Findings

The analysis revealed several important trends:

Patients diagnosed with diabetes generally exhibit significantly higher glucose levels compared to non-diabetic patients.
Individuals with diabetes tend to have higher BMI measurements, suggesting a strong association between obesity and diabetes risk.
Diabetes occurrence appears more frequently among older age groups.
Elevated glucose concentrations combined with high BMI values can serve as indicators for identifying patients at greater risk.
Population segmentation techniques allow healthcare providers to better understand patient demographics and support preventive healthcare strategies.
